# validation/exploratory: runs after the freeze

Exploratory runs made after the held-out predictions were frozen. They were never part of the test. [Back to the validation README](../README.md).

| [`console.log`](console.log) | Console output of the exploratory session |
| `calibration/`, `data/` | Calibration and timed runs of the exploratory configurations, laid out like `../calibration/` and `../data/` |
